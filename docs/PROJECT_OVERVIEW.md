# Project Overview

## What DocVerify Is

DocVerify is an identity verification platform focused on API delivery for fintech startups.

It processes ID documents, extracts key fields, and verifies a selfie against the face printed on the ID.

## Vision

- Build a reliable, developer-friendly KYC verification API.
- Serve fintech onboarding journeys with low integration friction.
- Provide model-backed face verification with clear confidence outputs.

## Core Offering

- Document ingestion and OCR
- Structured parsing and validation
- Authenticity and quality checks
- Face verification using our own model pipeline

## Users

- Fintech engineering teams integrating KYC APIs
- Risk and compliance teams consuming verification outputs
- Internal operations teams reviewing edge cases

## Current Status

- Working FastAPI backend with async processing endpoints
- React frontend for demos and operator validation
- Document and face verification pipeline wired end-to-end

## Near-Term Roadmap

1. Partner authentication and API management.
2. SLA/monitoring dashboards.
3. Persistent job storage and replayability.
4. Versioned API and integration SDKs.
